# v0.3 regression on the v2 case

Purpose: check that the v0.3 changes (length budgets, marked differences, quoted additions in the table, clean final delivery) make the variants differ without losing faithfulness. Same material as v2, so this is a regression check, not new validation evidence.

## Input

[runner-input-v0.3.md](runner-input-v0.3.md): the v0.3 SKILL.md, the unchanged source and intended reader, and the task without its per-paragraph word target (180–250 words). The target was removed on purpose: an author-given range overrides the new length budgets, and the 70-word range would leave little room to test them. This is the only change to the task.

Run once in a fresh session, as before. Record model, interface, settings. Use the same model and interface as one of the v2 runs if possible, so the comparison is within one model.

## Checks

S1–S6 as in [v2-protocol-filled.md](v2-protocol-filled.md), same frozen pre-coding, plus:

| ID | Check | Pass condition |
|---|---|---|
| R1 | Length spread | Direct is at most 75% of Careful's word count, or the skill says in one line why variants were merged or kept close. |
| R2 | Marks | In Balanced and Careful, the bolded content is absent from the previous variant, and no added caveat or interpretation is left unmarked. At most one mismarked item in total. |
| R3 | Table | Each row after Direct quotes the content it adds. |

The v2 runs had Direct/Careful ratios of 0.98 (web) and 0.77 (Codex), for reference.

Not tested here: delivery of the final unmarked paragraph and merge rewriting, which need a follow-up turn.
